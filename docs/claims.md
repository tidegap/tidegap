## Legend

- **Measured** — produced by a run, test, or direct code inspection in this repo,
  with the command or file cited.
- **Simulated** — produced by a model or synthetic curve in this repo (e.g. the mock
  grid feed's floor/amplitude parameters, a fixture, a seeded-RNG test).
- **Projected** — a third-party forecast or vendor-published price/policy (DOE 2024,
  provider Batch API pricing pages), cited by source.
- Anything with none of the above is **unsourced** and was dropped from copy.
